Як скласти власний файл гри

Файл гри — це текстовий файл з розширенням .json. Він замінює всі завдання гри, а за бажанням — і події, і саму дошку.

Найпростіший шлях: у грі натиснути «Завантажити зразок файлу», відкрити його в Блокноті або VS Code, замінити зміст і завантажити назад кнопкою «Завантажити файл гри». Якщо у файлі є помилка, гра покаже, у якому записі, і лишить попередній набір.

Скласти файл разом із ШІ-асистентом: скопіюйте інструкцію для ШІ в чат асистента, відповідайте на його запитання, а готовий JSON збережіть як .json. Факти після асистента перевіряйте самі.

Найменший файл: лише завдання

Обов'язкове лише поле tasks. Дошка, події й налаштування тоді лишаються зі зразка, а group прив'язує завдання до доби на дошці: rus, lit, koz, imp, xx.

{
  "title": "7 клас: Русь у період розквіту",
  "sources": ["Підручник «Історія України», 7 клас, автор, рік, с. 40–52"],
  "tasks": [
    { "kind": "choice", "group": "rus",
      "text": "Хто збудував Софійський собор у Києві?",
      "options": ["Ярослав Мудрий", "Володимир Великий", "Святослав", "Ольга"],
      "correct": "Ярослав Мудрий",
      "why": "Собор зведено за Ярослава Мудрого." }
  ]
}

Чотири види завдань

Це ті самі каркаси, що в довідковій картці курсу: питання, сортування, послідовність, підробка. Спільні правила для всіх видів:

  • помилка не показує правильної відповіді, бо завдання може повернутися;
  • why — коротке пояснення, гравці бачать його після успіху;
  • варіанти, елементи й кроки щоразу перемішуються, тому порядок у файлі нічого не видає.

choice — питання з варіантами

{ "kind": "choice", "group": "koz", "text": "…", "options": ["…", "…", "…"], "correct": "…", "why": "…" }

correct має збігатися з одним із варіантів дослівно, аж до лапок і крапки.

sort — сортування за скринями

{ "kind": "sort", "group": "koz", "text": "Розкладіть: з яким гетьманом пов'язана подія?",
  "bins": ["Богдан Хмельницький", "Іван Мазепа"],
  "items": [
    { "text": "Переяславська рада", "bin": "Богдан Хмельницький" },
    { "text": "Союз із Карлом XII", "bin": "Іван Мазепа" }
  ],
  "why": "…" }

Перша помилка закінчує завдання. Описуйте елемент ознаками, а не назвою скрині: «трипільський горщик» уже сам підказує відповідь.

sequence — послідовність

{ "kind": "sequence", "group": "xx", "text": "Відновіть послідовність подій.",
  "steps": ["перший крок", "другий", "третій", "четвертий"],
  "extra": ["чужий крок з іншого процесу"],
  "why": "…" }

У steps — правильний порядок, щонайменше три кроки. З extra гра домішує до двох чужих кроків. Не пишіть у кроках років: тоді порядок визначатиме порівняння чисел, а не розуміння. Завдання-послідовність ще й випускає з Порубу.

forgery — оригінал і підробка

{ "kind": "forgery", "group": "lit", "text": "Опис Львова кінця XVI ст. (умовний текст). Знайдіть, чого тоді бути не могло.",
  "parts": [
    { "t": "Місто живе за магдебурзьким правом.", "fake": false },
    { "t": "У ратуші засідає гетьман.", "fake": true }
  ],
  "why": "…" }

Анахронізм має бути в межах теми: установа, якої ще не було, посада, яку вже скасували, назва міста, якої воно ще не мало. Мобільний телефон у XVII ст. перевіряє кмітливість, а не історію.

Події «Хроніки» (events, необов'язково)

kindЩо робитьПоля
cardісторія + наслідокstory, effect (коротко), і будь-які з наслідків: money (±), move (±клітинок), goto ("jail" або номер клітинки), jailKey (true — грамота виходу з Порубу), perUpgrade (сума за кожен рівень укріплень)
decisionрішення без «правильного» варіанта, кожен має цінуtext, options: [{ "label", "outcome", …наслідки як у card }]
newsновина змінює оренду однієї добиtext, group, mult (0 — без оренди, 0.5 — половина, 2 — подвійна), laps (на скільки раундів), why

Якщо подій у файлі немає, лишаються події зразка. Якщо варіанти рішень вигадані, скажіть це в полі conditional, і гра покаже застереження на першому екрані.

Власна дошка (groups, cells, board, необов'язково)

"groups": [ { "id": "rus", "name": "Русь-Україна", "color": "#cfe0cc" } ],
"cells": [
  { "type": "start", "name": "Старт" },
  { "type": "land", "name": "Київ", "group": "rus", "price": 60, "rent": [6, 30, 90] },
  { "type": "trade", "name": "Солеварня", "price": 100 },
  { "type": "chronicle" }, { "type": "archive" },
  { "type": "tax", "name": "Мито", "amount": 100 },
  { "type": "jail", "name": "Поруб" }, { "type": "gotojail", "name": "Застава" },
  { "type": "slow", "name": "Бездоріжжя" }
]
  • land — земля доби, купується після успішного завдання. rent — оренда без укріплень, з одним і з двома.
  • trade — промисел, купується без завдання. Оренда росте з кількістю промислів у власника.
  • chronicle — подія, archive — завдання за винагороду, tax — мито.
  • jail — в'язниця, рівно одна. gotojail веде в неї. slow — пропуск ходу.
  • Перша клітинка — start.
  • Для кільця кількість клітинок має ділитися на 4 (20, 24, 28, 32…), кути — клітинки 0, n/4, n/2, 3n/4.

Маршрут на карті замість кільця: "board": { "layout": "map", "map": "…", "aspect": 1.333 }, і кожна клітинка має x та y у відсотках від ширини й висоти карти.

map можна задати двома способами:

  • адреса https://… — з умовою, що зображення можна вільно використовувати;
  • картинка, вбудована у файл як data:-URL.

Браузер не дозволяє завантаженому файлу читати сусідні файли з диска.

Налаштування (settings, необов'язково)

"settings": { "startMoney": 1000, "passBonus": 200, "timeLimitMin": 20, "dice": 2,
              "archiveBonus": 50, "jailFine": 50, "tradeRent": [25, 60, 120],
              "eventsInOrder": false }

eventsInOrder: true — «Хроніка» йде не навмання, а в порядку файлу. Складіть події хронологічно, і той, хто знає, що буде далі, вкладатиме гроші інакше: знання переходить з вікна завдання в рішення гравця.

Часті помилки

  • Кома після останнього елемента списку чи об'єкта: [1, 2, ].
  • Лапки «ялинки» або “лапки-лапки” замість прямих " навколо назв полів і рядків. Усередині тексту «ялинки» можна.
  • Апостроф усередині тексту можна писати як є: "з'їзд".
  • correct не збігається з варіантом дослівно.

Чесність гри

Перш ніж показувати гру учням, перевірте її п'ятьма питаннями з довідкової картки «Механіка і знання»: що зміниться від помилки, чи можна виграти без знання, де живе знання, і чи зміниться гра, якщо історичні питання замінити на математичні. Цей шаблон — чесний тип «б»: знання дає перевагу в грошах і землі, але здебільшого живе у вікні завдання. Найближче до типу «а» тут події-рішення й підробки: у них гравець, який розуміє добу, грає інакше.
