# Історія як гра

Вебігри для підготовки до НМТ з історії України.
Відкрийте `index.html` — працює і з хостингу, і з теки на флешці, без інтернету (крім завдань Wordwall).

Це публічне видання: до нього входить лише те, що не має чужого авторського права.
Факти ігор складено за офіційною програмою НМТ з історії України.
Малюнки «Розкопок» і графіка «Кафе на гілці» — власні; спрайти «Кари вікінга» й наративної гри — авторські.
«Дівчина з Поділля» В. Тропініна — суспільне надбання (Wikimedia Commons).
Звуки «Кари вікінга» — CC0 (Kenney, StumpyStrust), див. `games/kara-vikinha/sounds/LICENSE.md`.

Дані гри зберігаються лише у вашому браузері; викладачеві вони потрапляють, тільки якщо ви самі натиснете «Надіслати викладачу».
